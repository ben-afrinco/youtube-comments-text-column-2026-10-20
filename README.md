# Text-column dataset

This repository contains the extracted text column from the source CSV dataset.

- Extracted column: `comment_text`
- Rows: 1,616,742 (excluding the header)
- File: [`text_column.csv.gz`](./text_column.csv.gz)
- Decompress with: `gzip -d text_column.csv.gz`

The decompressed CSV contains one column named `comment_text`.
